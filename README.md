# Hasku & Tails: Vet Services Landing Page

Single-page landing page for the veterinary services at Hasku & Tails, Talegaon Dabhade, Pune.
Built to turn visitors from Google Ads and Search into appointment requests and WhatsApp enquiries.

## Services shown
Consultation, Diagnostic center, X-ray, Surgery, Pharmacy, Sonography (coming soon)

## Features
- Appointment request form that opens WhatsApp with the details filled in
- Check Price buttons that open WhatsApp for each service
- One-tap call buttons for urgent cases
- FAQ and local business structured data for search
- Mobile-first, one self-contained file

## Files
- `index.html`: the whole website

## Updating
Edit `index.html`, commit the change, and the live site updates within a few minutes.
